# Preparar revisión pública

Lee AGENTS.md y PUBLIC_RELEASE.md. Crea una copia limpia nueva con tools/prepare_public.py; no sobrescribas el original o una exportación anterior. Comprueba matrícula genérica configurable, código, recursos, historial Git, ejemplos y ausencia de información personal o claves. Audita con public_audit.py y revisa visualmente recursos; un escáner de texto no basta. Comprueba LICENSE Apache-2.0, NOTICE (Copyright 2026 Luis Zapien), THIRD_PARTY_NOTICES.md y los avisos empaquetados; revisa las licencias/derechos de cualquier componente nuevo. Si el encargo es solo compartir fuentes, no compiles ni generes APK: verifica el ZIP, los archivos y avisos, y documenta los resultados históricos y límites. Compilar requiere que el usuario solicite esa etapa. No crees un remoto, no hagas git push, no publiques APK ni cambies configuración del equipo. La licencia actual ya está autorizada y aplicada. Pídeme autorización para publicar, generar/cargar una clave o instalar; no infieras esos permisos de la selección de licencia.
